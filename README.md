# Landing Page Servis AC

Landing page statis untuk jasa Servis AC Bantul Yogyakarta.

## GitHub Pages

File yang siap dipublish ada di folder `docs/`.

Pengaturan GitHub Pages:

- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/docs`

URL setelah Pages aktif:

https://maspandu2308-sys.github.io/landing-page-servis-ac/

## Struktur

- `docs/index.html` - halaman yang dipublish GitHub Pages
- `docs/assets/` - gambar dan video yang dipakai halaman
- `index.html` - sumber HTML asli
- `src/` - source dan aset dari bundle awal

## Development Opsional

Jika npm tersedia, proyek ini juga bisa dijalankan sebagai proyek Vite:

```bash
npm install
npm run dev
npm run build
```
